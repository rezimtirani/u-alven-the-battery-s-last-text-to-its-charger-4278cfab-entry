The phone battery's last text to the charger it waited for all day: it held 1% while the charger sat across the room, and now that it is at 0 it asks the charger to tell its apps it loved them — and to delete its search history.

> I held 1% all day while you sat across the room. I'm at 0 now — tell my apps I loved them, and delete my search history.

## How it works

`main.py` (Python 3 standard library only) writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
